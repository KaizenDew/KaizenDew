I build things that make my own day easier: a Turkish-speaking desktop AI assistant, a shared memory for my AI coding agents, and running apps for my phone. I work side by side with AI agents (Claude Code, Codex) and ship in small, tested steps. This profile is a running log: it shows what actually exists and what is still in progress.
