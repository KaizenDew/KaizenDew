Hi, I'm **Kaizen**. I build tools that make my own day easier, and then keep making them a little better.
Above is my workbench. Every building is a real project. Switch GitHub to dark mode and the lights come on.

## 📐 building code

The rules every building on this bench follows:

1. **Small blocks.** One change at a time, and each one is checked before the next goes on top.
2. **Local first.** Data stays on your device unless it really needs to leave.
3. **AI is a partner, not autopilot.** I build with Claude Code and Codex, and give them a shared memory (beynim) so they remember decisions and don't make them up.
4. **Honest status.** If it isn't done, this page says so.
